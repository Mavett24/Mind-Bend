# Code of conduct

Mind Bend follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep feedback about the work, not the person. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else in this project.

To report a problem, email mmfavetta@gmail.com. Reports are read by the maintainer and kept confidential.
