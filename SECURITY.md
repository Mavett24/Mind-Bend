# Security

Mind Bend has no backend, no accounts and no database. Game history stays in the player's browser, and Google Analytics only loads after an explicit accept (see [`/privacy`](https://mind-bend.vercel.app/privacy)).

If you find a security or privacy problem, please report it privately through [GitHub's private vulnerability reporting](https://github.com/Mavett24/Mind-Bend/security/advisories/new) rather than in a public issue. I'll reply as soon as I can.

Only the latest version on `main`, deployed at [mind-bend.vercel.app](https://mind-bend.vercel.app), is supported.
